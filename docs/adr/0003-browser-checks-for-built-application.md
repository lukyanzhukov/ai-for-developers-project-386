# Проверять гостевой переход в собранном приложении

Проверки HTML подтверждают тексты и адреса ссылок, но не доказывают, что JavaScript запускается, переходы работают и страницы помещаются на экране телефона. Поэтому дополняем тесты рендеринга React и HTTP-проверки браузерными сценариями в Chromium через Playwright, запуская их в существующем Vitest против собранного приложения.

На экранах 1280 × 900 и 390 × 844 проверяем путь «Записаться» → `/booking` → «На главную», обновление `/booking` и отсутствие горизонтальной прокрутки на обеих страницах. Проверки входят в общий `mise run check`, который вызывают pre-push и GitHub Actions; установка браузера включена в `mise run install`, а созданные браузер и сервер завершаются и при ошибке.

Это добавляет загрузку Chromium и его системных зависимостей при подготовке окружения, зато проверяет маршрут `/booking` вместе с выдачей фронтенда сервером после сборки. Покрытие ограничено Chromium и указанными размерами экрана; проверки бронирования появятся при реализации соответствующего сценария.
