# Один владелец календаря и общая занятость

Сервис предназначен для записи к одному заранее заданному владельцу календаря: он создаёт типы встреч с названием, описанием и длительностью и просматривает предстоящие встречи всех типов. Гость записывается без регистрации, выбирая тип встречи и свободный слот на ближайшие 14 календарных дней; длительность слота определяется выбранным типом встречи.

Занятость общая для всех типов встреч, поскольку встречи занимают время одного человека. Полные и частичные пересечения запрещены, включая одновременные запросы: из двух конфликтующих записей успешна только одна; следующая встреча может начаться ровно в момент окончания предыдущей.

Это целевая модель из [описания проекта](../../README.md#сценарий-записи-на-звонок), подтверждённая при согласовании первой фичи; бронирование пока не реализовано. Начало окна записи, рабочие дни и часы, часовой пояс и шаг доступных стартов остаются открытыми до согласования календаря.
