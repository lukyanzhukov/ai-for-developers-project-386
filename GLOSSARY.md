# Календарь звонков

Сервис записи гостей на встречи с одним заранее заданным владельцем календаря.

## Термины

**Владелец календаря**:
Единственный человек, к которому записываются гости. Создаёт типы встреч и просматривает предстоящие встречи всех типов.

**Гость**:
Человек, который записывается на встречу без регистрации.

**Тип встречи**:
Вариант встречи с названием, описанием и длительностью.

**Слот**:
Интервал времени для записи длительностью выбранного типа встречи. Занятый интервал недоступен для всех типов встреч, включая частичные пересечения.

**Запись**:
Подтверждённая встреча гостя с владельцем календаря в выбранном слоте. Сам выбор слота записью не является.
