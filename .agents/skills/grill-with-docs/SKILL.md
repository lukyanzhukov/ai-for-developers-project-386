Call the Skill tool twice, for "grilling" and "domain-modeling".

When all design questions are settled, finish the agreed glossary and decision updates. Present a specification for user review: the goal, scope, acceptance criteria, any open questions, and links to changed documents.

End the turn with this review handoff. Agreement on interview answers confirms the requirements; implementation starts on a separate explicit user instruction, using "implement".
